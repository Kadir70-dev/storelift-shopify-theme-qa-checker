Scope, methodology and limitations

Scans were initiated by the reviewer, using only the currently loaded DOM in each chosen browser tab. The open-tab audit checks only already-open tabs on the same origin after explicit permission. Optional internal link verification performs limited HTTP HEAD requests without cookies; it never crawls external sites, issues GET requests to checkout endpoints, or performs purchases. Layout observations are for the actual measured viewport, not simulated mobile. This is not a Google ranking, Lighthouse measurement, conversion result, WCAG certification, or a guarantee that all defects are caught.

Chrome storage is local to this browser profile. Notes and acceptance statuses are saved locally. No remote backend, analytics or AI API is called by the extension.
