Frequently asked questions

Does the extension require a Shopify account or API key?
No. It reads the publicly visible DOM of any page you have open in Chrome. No login, no token, no backend.

Does it work on password-protected or private storefronts?
Only on pages you can already view in Chrome. If the storefront requires a password, log in first, then run the scan on the unlocked page.

Why does "Verify internal links" ask for host permission?
To send HEAD requests to that store's URLs. The permission is scoped to that exact origin and is not stored permanently — Chrome will ask again next session unless you click "Always allow".

The score says 100 but I can see problems on the page — why?
The score reflects only the checks the extension can detect automatically from the loaded DOM. JavaScript-rendered content, shadow DOM, lazy-loaded images, and anything that loads after the page finishes may be missed. Always manually verify findings before client delivery.

How do I delete all saved scan data?
Open the extension popup → Session history → "Clear all sessions". All data is wiped from chrome.storage.local immediately.

Is this affiliated with Shopify?
No. StoreLift Theme QA Checker is an independent developer tool. It is not affiliated with or endorsed by Shopify Inc.
