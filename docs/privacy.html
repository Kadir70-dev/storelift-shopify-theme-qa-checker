StoreLift — Shopify Theme QA Checker

Privacy Policy · Last updated: 2026-11-09

Overview

StoreLift Theme QA Checker ("the Extension") is a browser-only developer tool for quality-checking Shopify storefronts. No data leaves your browser. No backend server, no account, no telemetry.

What the Extension reads

When you run a scan, the Extension reads the already-loaded DOM of the active tab you clicked it on:

  • Page title, meta description, canonical URL, robots meta tag
  • H1 heading count
  • Image src and alt attributes (to detect missing alt text and broken images)
  • Anchor href attributes (to detect empty or non-navigating links)
  • Visible text content (to detect placeholder/demo text such as "Lorem ipsum")
  • JSON-LD structured data blocks
  • Presence of cart form and shipping/return link text
  • Viewport width at time of scan

When you choose Verify internal links, the Extension sends HTTP HEAD requests to same-origin product, collection, page, and policy URLs to check for potential 404 responses. These requests go only to the Shopify store origin you are already viewing, use credentials: 'omit', and carry no user session data.

What the Extension stores

Scan results (page URL, findings list, score, timestamps) are saved in chrome.storage.local — your browser's local extension storage, on your device only. Up to 24 sessions and 20 pages per session are retained.

No data is stored outside your device. You can delete all stored data at any time using the "Clear all sessions" button in the Extension popup.

What the Extension does NOT collect

  • No personal information (name, email, account credentials)
  • No Shopify admin API tokens or store passwords
  • No payment or financial data
  • No browsing history beyond the tab you explicitly scan
  • No analytics, telemetry, or crash reporting
  • No cookies

Data transmission

The Extension does not transmit any data to any server operated by StoreLift or any third party.

The only outbound network activity it may perform:

  • HEAD requests to the scanned store's own origin — only when you use "Verify internal links"; these go to the Shopify store you are already viewing, not to any StoreLift server.

There is no backend, no analytics endpoint, and no cloud sync.

The Extension is a developer tool not directed at children. It does not knowingly collect any information from children under 13.
